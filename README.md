## 🔍 Overview & Industry SEO Context

This repository tracks notable **SaaS platforms** and **open-source projects** for **Electric Vehicle Charging Management**. These software solutions enable Charge Point Operators (CPOs), eMobility Service Providers (eMSPs), fleet managers, and utility companies to monitor EV charging station networks, process automated billing, optimize grid loads, and ensure compliance with open industry standards like **OCPP 1.6 / 2.0.1**, **OCPI**, and **ISO 15118**.

## 🛠️ Open-Source GitHub Projects

The open-source EV charging ecosystem offers production-grade **CSMS backends**, **microcontroller firmware**, **ISO 15118 V2G engines**, and **OCPP protocol libraries**.

*Repos are sorted below by GitHub Stars_Count (descending):*

### 🌟 Open-Source Repositories Directory

1. **[evcc](https://github.com/evcc-io/evcc)** ☀️ <a href="https://github.com/evcc-io/evcc/stargazers"><img src="https://img.shields.io/github/stars/evcc-io/evcc?style=social" alt="evcc Stars"/></a>
   - **Tech & License**: `Go` | `MIT`
   - Extensible solar EV charging controller and home energy management system supporting 100+ wallboxes, smart meters, and solar inverters.

2. **[OpenEVSE Firmware](https://github.com/OpenEVSE/open-evse-v4)** ⚡ <a href="https://github.com/OpenEVSE/open-evse-v4/stargazers"><img src="https://img.shields.io/github/stars/OpenEVSE/open-evse-v4?style=social" alt="OpenEVSE Stars"/></a>
   - **Tech & License**: `C++` | `GPL-3.0`
   - Open hardware charging station firmware for OpenEVSE controllers supporting MQTT, OCPP 1.6, and solar PV diversion.

3. **[mobilityhouse/ocpp](https://github.com/mobilityhouse/ocpp)** 🐍 <a href="https://github.com/mobilityhouse/ocpp/stargazers"><img src="https://img.shields.io/github/stars/mobilityhouse/ocpp?style=social" alt="mobilityhouse/ocpp Stars"/></a>
   - **Tech & License**: `Python` | `MIT`
   - The official Python implementation of the Open Charge Point Protocol (OCPP) supporting versions 1.6, 2.0.1, and 2.1.

4. **[EVerest Core](https://github.com/EVerest/everest-core)** 🚀 <a href="https://github.com/EVerest/everest-core/stargazers"><img src="https://img.shields.io/github/stars/EVerest/everest-core?style=social" alt="EVerest Core Stars"/></a>
   - **Tech & License**: `C++` | `Apache-2.0`
   - LF Energy open-source EV charging station firmware stack supporting OCPP 1.6/2.0.1, ISO 15118 V2G, and dynamic load management. Backed by Linux Foundation, PIONIX, ABB, Siemens, and Tesla.

5. **[SteVe](https://github.com/steve-community/steve)** ☕ <a href="https://github.com/steve-community/steve/stargazers"><img src="https://img.shields.io/github/stars/steve-community/steve?style=social" alt="SteVe Stars"/></a>
   - **Tech & License**: `Java` | `GPL-3.0`
   - Established open-source OCPP server implementation developed at RWTH Aachen University (*Steckdosenverwaltung*). Supports OCPP 1.2, 1.5, and 1.6 (JSON & SOAP).

6. **[MicroOcpp](https://github.com/matth-x/MicroOcpp)** 🔬 <a href="https://github.com/matth-x/MicroOcpp/stargazers"><img src="https://img.shields.io/github/stars/matth-x/MicroOcpp?style=social" alt="MicroOcpp Stars"/></a>
   - **Tech & License**: `C++` | `MIT`
   - Lightweight C++ OCPP 1.6/2.0.1 client library engineered for microcontrollers (ESP32, ESP8266, STM32, and Arduino).

7. **[Java-OCA-OCPP](https://github.com/ChargeTimeEU/Java-OCA-OCPP)** ☕ <a href="https://github.com/ChargeTimeEU/Java-OCA-OCPP/stargazers"><img src="https://img.shields.io/github/stars/ChargeTimeEU/Java-OCA-OCPP?style=social" alt="Java-OCA-OCPP Stars"/></a>
   - **Tech & License**: `Java` | `MIT`
   - Java client and server protocol library implementation for OCPP 1.6 and 2.0 as specified by the Open Charge Alliance.

8. **[Flexo V2G Engine](https://github.com/flexo-energy/flexo)** 🔋 <a href="https://github.com/flexo-energy/flexo/stargazers"><img src="https://img.shields.io/github/stars/flexo-energy/flexo?style=social" alt="Flexo Stars"/></a>
   - **Tech & License**: `TypeScript` | `Apache-2.0`
   - Open-source smart charging, V2G battery optimization engine, and demand response controller.

9. **[RISE-V2G](https://github.com/V2G-FH-Dortmund/RISE-V2G)** 🚗 <a href="https://github.com/V2G-FH-Dortmund/RISE-V2G/stargazers"><img src="https://img.shields.io/github/stars/V2G-FH-Dortmund/RISE-V2G?style=social" alt="RISE-V2G Stars"/></a>
   - **Tech & License**: `Java` | `MIT`
   - Reference implementation of ISO 15118 and DIN 70121 Vehicle-to-Grid (V2G) communication standards.

10. **[Open e-Mobility](https://github.com/sap-labs-france/ev-server)** 🌐 <a href="https://github.com/sap-labs-france/ev-server/stargazers"><img src="https://img.shields.io/github/stars/sap-labs-france/ev-server?style=social" alt="Open e-Mobility Stars"/></a>

11. **[CitrineOS](https://github.com/citrineos/citrineos-core)** 💎 <a href="https://github.com/citrineos/citrineos-core/stargazers"><img src="https://img.shields.io/github/stars/citrineos/citrineos-core?style=social" alt="CitrineOS Stars"/></a>

## 📈 Market Size & Industry Structure

```
                  Global EV Charging Software Market Growth
   $8.0B ----------------------------------------------------------- $7.18B (2030)
   $6.0B --------------------------------------------------- 📈
   $4.0B ----------------------------------------- 📈
   $2.0B --------------------------------- 📈
   $1.5B --------- $1.52B (2025)
   $0.0B +---------+---------+---------+---------+---------+---------+
                   2025      2026      2027      2028      2029      2030
```

- **Market Dynamics**: Driven by government mandates (NEVI in US, AFIR in EU), EV fleet transition, and demand for ISO 15118 Plug & Charge capabilities.
- **CPMS Architectural Stacks**: Standard stack combines **EVerest** or **OpenEVSE** at hardware firmware tier, **CitrineOS** or **SteVe** at server CSMS layer, and custom cloud apps via **ocpp-js** / **mobilityhouse/ocpp**.
